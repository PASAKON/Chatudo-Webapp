วิธีขอลบข้อมูล

มีผลบังคับใช้ตั้งแต่วันที่ [รอยืนยัน: วันที่มีผลบังคับใช้]

English version

หากลูกค้าของร้านค้าที่ใช้ Chatudo ต้องการให้ลบข้อมูลส่วนบุคคลที่เกี่ยวข้องกับการสนทนาผ่าน Chatudo ทำตามขั้นตอนด้านล่าง

  1. ส่งคำขอมาให้เรา

    ส่งอีเมลมาที่ [รอยืนยัน: อีเมลติดต่อ] พร้อมระบุชื่อร้านค้า ช่องทางที่ใช้งาน (LINE OA / Messenger / Instagram) และบัญชีที่ต้องการให้ลบข้อมูล (ช่องทางหลักที่แนะนำ) หรือพิมพ์คำขอในแชทที่คุยกับร้านค้าที่ใช้ Chatudo อยู่ เช่น พิมพ์ว่า “ขอลบข้อมูล” แล้วร้านค้าจะส่งคำขอต่อมาให้เรา

  2. เราตรวจสอบคำขอ

    ทีมงานยืนยันตัวตนผู้ขอและตรวจสอบว่าข้อมูลที่จะลบตรงกับบัญชีที่ระบุ เพื่อป้องกันการลบข้อมูลผิดบัญชี

  3. ดำเนินการลบ

    ข้อมูลที่เกี่ยวข้องกับบัญชีที่ขอจะถูกลบภายใน [รอยืนยัน: ระยะเวลาดำเนินการลบข้อมูล] นับจากวันที่เราตรวจสอบคำขอเสร็จสิ้น

  4. ยืนยันผลให้ทราบ

    เราจะส่งอีเมลหรือข้อความยืนยันกลับไปเมื่อการลบข้อมูลเสร็จสมบูรณ์

ข้อมูลที่จะถูกลบ

  • ข้อความสนทนาที่เก็บไว้ในระบบซึ่งเกี่ยวข้องกับบัญชีที่ขอ
  • ชื่อที่แสดงและรูปโปรไฟล์ที่จัดเก็บไว้สำหรับบัญชีนั้น
  • รหัสประจำตัวผู้ใช้บนแพลตฟอร์ม (platform user ID) ที่ผูกกับบัญชีนั้น

ข้อมูลบางส่วนที่กฎหมายกำหนดให้ต้องเก็บไว้ (เช่น เพื่อการตรวจสอบทางบัญชีหรือข้อพิพาท) อาจเก็บต่อไปตามระยะเวลาที่กฎหมายกำหนด แม้จะได้รับคำขอลบข้อมูลแล้ว
