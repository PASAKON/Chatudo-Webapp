Thai version (ภาษาไทย)

If a shop’s customer using Chatudo wants their personal data related to conversations through Chatudo deleted, follow the steps below.

  1. Send us your request

    Email [TBC: contact email] with the shop’s name, the channel used (LINE OA / Messenger / Instagram), and the account you want deleted (recommended primary route), or type the request in the chat with the shop that uses Chatudo, e.g. type “delete my data”, and the shop will forward the request to us.

  2. We verify the request

    Our team verifies the requester’s identity and checks that the data to be deleted matches the account specified, to prevent deleting the wrong account.

  3. We carry out the deletion

    Data related to the requested account is deleted within [TBC: deletion turnaround time] from the date we finish verifying the request.

  4. We confirm the result

    We will send an email or message confirming once the deletion is complete.

Data That Gets Deleted

  • Conversation data stored in the system related to the requested account
  • Display name and profile picture stored for that account
  • The platform user ID linked to that account

Some data the law requires us to keep (e.g. for accounting or dispute records) may be retained for the period the law requires, even after a deletion request.
